## 🌿 About the Project

> *"True vision is not merely what is seen—it is the lens through which identity is articulated."*

**Nazario** is a concept store for luxury eyewear and artisan sunglasses designed to bring an editorial catalog experience to the browser. Designed with an ultra-clean, emerald-tinted editorial layout, it bridges high-fashion boutique aesthetics with performance-first vanilla web standards.

* 👓 **Editorial Cataloging** — Tailored product arrangements modeled after high-end European fashion boutiques.
* 🌿 **Cohesive Emerald Theme** — Harmonious palette of forest greens, mint highlights, and ivory whites.
* 📱 **Fluid Responsiveness** — Pixel-perfect rendering across mobile viewports, tablets, and ultra-wide displays.
* ⚡ **Zero-Dependency Core** — Ultra-fast load times with pure vanilla JS execution and streamlined CSS.

## ✨ Core Features

| Module | Technical Implementation | Purpose |
| :--- | :--- | :--- |
| **Bespoke Product Showcase** | CSS Flexbox & CSS Grid | Editorial magazine-style product arrangements |
| **Dual Framework Synthesis** | Bootstrap Grid + Tailwind Utilities | Rock-solid responsive scaffold with rapid, exact micro-styling |
| **Micro-Interactions** | CSS Transitions + Pure JS DOM events | Subtle hover lift states, smooth drawer open/close |
| **Fluid Adaptive Nav** | Responsive Hamburger Drawer | Effortless mobile menu navigation with touch targets |
| **Optimized Asset Pipeline** | Responsive images + cached CDN delivery | Instant load times and zero Cumulative Layout Shift (CLS) |
