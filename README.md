## 👓 About Nazario

> *"The frame does not define the gaze—it frames your perspective."*

**Nazario** is a concept digital boutique devoted solely to designer eyeglasses and artisan sunglasses. Styled with an emerald glassmorphism finish, high-contrast typography, and fluid micro-animations, it provides an ultra-luxurious browsing experience without heavy JavaScript bloat.

* 🔬 **Pure Eyewear Focus** — Zero generic apparel distractions; built strictly for optical collectors.
* 🌿 **Emerald Atelier Theme** — Deep forest canvases balanced with luminous mint borders and gold-leaf accents.
* ⚡ **Ultra-Responsive Layout** — Adaptive product cards tailored for 4K desktop down to compact touchscreens.
* 🪶 **Zero Build Overhead** — Native browser execution using optimized HTML5, Tailwind CSS, Bootstrap, and vanilla JS.
